# 🏠 SmartNest – Smart Home Monitoring & Control System

SmartNest is a mobile-based **Smart Home Monitoring and Control System** developed for the **SCS 3311 – Mobile Application Design & Development Mini Project**.

The project consists of:

- 📱 React Native mobile application
- 🌐 Web-based hardware simulator
- ☁️ Firebase Realtime Database
- ⚡ Real-time smart device monitoring
- 🏢 Multi-floor home management
- 🎛️ Multi-switch device control
- 🔥 Safety-critical device handling
- 📷 Security camera monitoring
- 📊 Energy usage monitoring

The system simulates a real-world IoT smart home environment without requiring physical smart-home hardware.

---

# 📌 Project Objective

The objective of SmartNest is to provide users with a mobile application for monitoring and controlling smart-home devices while maintaining real-time communication with a cloud-connected hardware simulator.

The system supports different device types including:

- Smart lights
- Electrical outlets
- Multi-switch units
- Safety-critical devices such as clothing irons
- Security cameras

Device status changes are synchronized between the mobile application, Firebase Realtime Database, and the web-based hardware simulator.

🚀 Running the Mobile Application

Navigate to the mobile project:
cd mobile

Install dependencies:
npm install

Start the Expo development server:
npx expo start

🌐 Running the Hardware Simulator

Navigate to the simulator project:
cd simulator

Install dependencies:
npm install

Start the development server:
npm run dev
